# Acme Return Policy

## Return window
Acme accepts returns within 30 days of delivery. Items must be unused and in original packaging.

## Refunds
Approved refunds go back to the original payment method within 5-7 business days. Acme's "Happy Return Guarantee" covers defective items with free return shipping.

## Exceptions
Final-sale items and gift cards cannot be returned. Refund exceptions require approval from a support specialist.
